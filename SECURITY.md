# Security Policy

The **EFDSOE Foundation** takes the security and integrity of our open-source projects and digital infrastructure seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in any EFDSOE repository or on `fseda.org`, please report it responsibly:

- **Email:** [info@fseda.org](mailto:info@fseda.org)
- **Subject:** `[SECURITY] Brief description of the issue`

Please do **not** open public issues for undisclosed vulnerabilities. We aim to acknowledge every report within **48 hours** and provide regular updates until resolution.
