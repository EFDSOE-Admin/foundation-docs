# EFDSOE Foundation – Governance & Documentation

Welcome to the official documentation repository of **EFDSOE** (*Independent Foundation for Digital Sovereignty, Sustainable Innovation & Open Source*), based in Graz, Austria.

This repository serves as the public reference for our institutional charter, open-source licensing principles, transparency guidelines, and security policies.

---

### 📋 Contents
- **`CHARTER.md`** – Mission, core values, and governance principles.
- **`SECURITY.md`** – Vulnerability disclosure policy and official security contact.
- **`CONTRIBUTING.md`** – How researchers, developers, and partners can collaborate with us.

---

### 🧭 Core Principles
1. **Digital Sovereignty:** Public infrastructure and critical software must remain open, auditable, and free from vendor lock-in.
2. **Sustainable Impact:** Technological progress must serve long-term societal and ecological resilience.
3. **Radical Transparency:** Documentation, architectural decisions, and funding guidelines are published openly by default.
